Motion and performance

Reactive means two things. Every change in the data is visible: it moves once, smoothly, in place. And the dashboard never stutters: 60 fps while panning with Panels open, on a mid-range phone.

Every data change has one motion

With reduced motion on, every row becomes an instant swap. Nothing loops except the live dot and an unacknowledged takeover border.

Performance rules

These are acceptance lines on every dashboard ticket, not a later polish pass.

Animate only transform and opacityNever width, height, top, left or box-shadow in a loop.
A poll that changes nothing re-renders nothingCompare the snapshot before setting state. Markers update in place, never rebuilt.
No layout shiftTabular figures, fixed-width value slots, reserved space for tags that come and go.
60 fps panning, under 8 ms per pollMeasured on a mid-range phone with Panels open.
Blur on desktop onlyBackdrop blur over a moving map is the most expensive thing here. Phones use a solid surface.
Keep the test aria-labelsRestyling never renames the labels the tests query.

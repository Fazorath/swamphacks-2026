Foundations

Color roles

Two layers. Primitives are the raw palette and appear only in the theme file. Roles say what a color is for, and they are the only names components use. To re-theme, change which primitive each role points to. The palette is expected to change; the roles are not.

Contrast is measured against --surface-panel, the darkest surface text sits on. The rule is 7:1, and 4.5:1 only for --text-dim.
